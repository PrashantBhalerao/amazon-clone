# 🛒 Amazon Clone

A fully responsive Amazon Clone built using HTML, CSS, and JavaScript.  
This project recreates the look and feel of the Amazon website with a modern and responsive user interface.

---

## 🚀 Features

- Responsive Design for All Devices
- Amazon Inspired Homepage
- Navigation Bar with Search Box
- Product Sections & Cards
- Hero Banner
- Hover Effects & Animations
- Shopping Cart UI
- Mobile Friendly Layout
- Clean and Modern Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 📱 Responsive Design

This website is optimized for:

- Desktop 💻
- Tablet 📱
- Mobile 📲
